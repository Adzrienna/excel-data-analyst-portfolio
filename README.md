# Excel Data Cleaning & Analysis Portfolio

## About This Portfolio

Welcome to my Excel Data Analyst Portfolio! This repository showcases my practical learning in data cleaning, data preparation, and data analysis using Microsoft Excel.

Through these projects, I worked with a fleet equipment inventory dataset to practise improving data quality and summarizing information using Excel tools.

## Projects

### 1. Fleet Inventory Data Cleaning

**File:** `Fleet_Inventory_Data_Cleaning.xlsx`

**Objective:** Prepare fleet inventory data for further analysis.

**Tasks performed:**
- Adjusted column widths to improve readability.
- Identified and removed empty rows.
- Checked for duplicate records.
- Reviewed spelling and corrected errors where identified.
- Removed double spaces using Find and Replace.
- Consolidated department names using Flash Fill.
- Reviewed the resulting dataset.

**Skills demonstrated:** Data cleaning, data quality checks, Excel data-management tools, and Flash Fill.

### 2. Fleet Inventory Analysis Using PivotTables

**File:** `Fleet_Inventory_PivotTable_Analysis.xlsx`

**Objective:** Summarize fleet equipment inventory data and explore equipment distribution.

**Tasks performed:**
- Formatted the dataset as an Excel table.
- Calculated SUM, AVERAGE, MIN, MAX, and COUNT.
- Created PivotTables to summarize equipment counts by department.
- Sorted results by equipment count in descending order.
- Explored equipment classes within departments and departments within equipment classes.

**Skills demonstrated:** PivotTables, summary statistics, data aggregation, sorting, and exploratory data analysis.

## Tools Used
